# Security

Ravenry runs coding agents in terminals, answers them from a phone and
reaches other machines over ssh, so a security problem in it can matter.
Thank you for reporting one privately.

## How to report

Use GitHub's private vulnerability reporting: on this repository, open the
**Security** tab, then **Report a vulnerability**. Only the maintainer sees
the report. Please do not open a public issue, pull request or discussion
about it.

Say what is affected (the Mac app, the Android or iPhone app, the hub,
`ravenryd`, the download page), the version, how to reproduce it and what
an attacker gains. A proof of concept helps.

## What happens next

- You get an answer within a week.
- The problem is confirmed or explained, then fixed in a release.
- You are credited in the release notes, unless you would rather not be.

Please give us a reasonable time to ship the fix before you publish
anything about it.

## Supported versions

The latest release of each app. The npm board (`ravenry-app` 0.4.x on npm)
is no longer maintained: the Mac app replaces it.
