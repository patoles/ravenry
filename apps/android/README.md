# Ravenry Android app

Placeholder. Nothing is built here yet.

The Android app will be a Kotlin shell around a WebView that shows the
board and the terminals, with native alerts and buttons for the moments a
session needs you. It reaches the home machine's hub over TLS on the home
Wi-Fi or a Tailscale network, pins the key the pairing QR code carries, and
holds a per-device token that can be revoked (../../docs/ARCHITECTURE.md).
